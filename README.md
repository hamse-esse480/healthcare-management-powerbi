# Healthcare Management & Service Utilization Dashboard

An interactive Power BI portfolio project exploring patient activity, appointments, treatments, doctor workload, billing, and revenue.

## Dashboard

The Power BI report includes seven pages:

1. Executive Overview
2. Patient & Appointment Analysis
3. Treatment Analysis
4. Billing & Revenue
5. Doctor Details
6. Patient Details
7. Details

The report uses a connected model with patient, doctor, appointment, treatment, billing, and date tables, with drillthrough to doctor- and patient-level views.

## Tools & Skills

- Microsoft Power BI Desktop
- Power Query
- DAX measures
- Data modeling and relationships
- Interactive visuals, slicers, cross-filtering, and drillthrough
- Healthcare service-utilization and revenue analysis

## Main Findings

The documented analysis reports that patients aged 30–44 represented the largest age group (34%), 51.5% of appointments were no-shows or cancellations, chemotherapy was the most common treatment type (24.5%), and total revenue was 551.25K across 200 bills. Monthly appointment, treatment, and revenue patterns are described in the [full documentation](docs/README.md).

## Interpretation Note

Findings are descriptive and should not be interpreted as causal effects. Please refer to the project documentation for definitions, methods, and interpretation details.
